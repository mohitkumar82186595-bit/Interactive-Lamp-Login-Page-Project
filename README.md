# Interactive-Lamp-Login-Page-Project
💡 **Interactive Lamp Login Page | HTML + CSS + JavaScript**

A small UI concept, but with a big focus on **animation, interaction, and visual experience**! 🚀

I created this **Interactive Lamp Login Page** using pure:

🔹 HTML
🔹 CSS
🔹 JavaScript

✨ **Key Features:**
• Interactive pull-chain lamp animation
• Lamp ON/OFF effect
• Warm ambient lighting & glow
• Animated glassmorphism login card
• Username & Password fields
• Interactive Sign In button
• Button hover & shine animation
• Login validation & success message
• Smooth transitions and micro-interactions
• Responsive design

The main idea was to make a simple login screen feel more **dynamic and realistic** instead of using a traditional static form.

🎯 **What I practiced:**
CSS positioning, gradients, shadows, glassmorphism, transitions, animations, DOM manipulation, event handling, and responsive UI design.

This project is a great example of how **HTML + CSS + JavaScript can create impressive UI experiences without using any framework.** 🔥
